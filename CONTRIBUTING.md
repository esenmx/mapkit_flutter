# Contributing

1. `flutter pub get`
2. Run what CI runs:

   ```sh
   git ls-files -z -- '*.dart' |
     xargs -0 dart format --output=none --set-exit-if-changed
   flutter analyze --fatal-infos --fatal-warnings
   flutter test
   flutter pub publish --dry-run
   npx --yes markdownlint-cli2@0.23.3
   dart run tool/check_snippets.dart \
     --import package:mapkit_flutter/mapkit_flutter.dart \
     --import package:flutter/material.dart --import dart:typed_data
   ```

   The last command analyzes every `dart` code block in `README.md` and
   `skills/*/SKILL.md` with the package's lints; a block preceded by
   `<!-- no-compile -->` is skipped.

3. Add a line under `## Unreleased` in `CHANGELOG.md` for every user-visible
   change.

Releases are published manually by the maintainer.

## Platform channel

The Dart↔Swift boundary is generated by
[Pigeon](https://pub.dev/packages/pigeon) from
[`pigeons/messages.dart`](pigeons/messages.dart). After editing the schema,
regenerate:

```sh
dart run pigeon --input pigeons/messages.dart &&
  dart format lib/src/messages.g.dart
```

The outputs (`lib/src/messages.g.dart`,
`darwin/mapkit_flutter/Sources/mapkit_flutter/messages.g.swift`) are committed
and must not be hand-edited; CI regenerates them and fails on drift.
