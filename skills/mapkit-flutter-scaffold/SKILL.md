# mapkit-flutter-scaffold

One import: `package:mapkit_flutter/mapkit_flutter.dart`. Every public type uses Apple's exact MapKit symbol name (`MKMapView`, `MKMapCamera`, `MKCoordinateRegion`, `MKPointAnnotation`, `MKPolyline`/`MKPolygon`/`MKCircle`/`MKTileOverlay`, `MKPointOfInterestFilter`, `MKStandardMapConfiguration`, `CLLocationCoordinate2D`, `CGLineCap`…). Predict from Swift MapKit; only divergences matter. Floor: iOS 17 / macOS 14.

## Core model & contracts

- **Declarative `MKMapView`**: pass `Set<MKPointAnnotation>`/`Set<MKPolyline>`/…; diffed on rebuild against what the map last accepted (new set or in-place mutation + `setState` both work). Same id + changed fields -> update; absent -> removed. No renderer objects: presentation props sit on models (`icon:`, `alpha:`, `isDraggable:`, `zPriority:`, `clusteringIdentifier:`, `strokeColor:`, `lineWidth:`, `lineDashPattern:`).
- **Phantom IDs**: `MKAnnotationId('x')`, `MKPolylineId('x')`, … — distinct per kind, unique (duplicate throws `ArgumentError` on build).
- **Strict validation (every build mode)**: invalid values throw `ArgumentError` (no clamping: lat outside `[-90,90]`, non-finite, negative width/radius, alpha outside `[0,1]`, pitch outside `[0,90)`, min>max zoom, 1 gradient color, `imagePixelRatio <= 0`), so value types have no `const` ctors. Longitude wraps into `[-180,180)`. `MKCameraZoomRange.unbounded` is the const default. `MKPolyline`/`MKPolygon`/`MKPointOfInterestFilter.including`/`.excluding` copy lists unmodifiably (not `const`: `MKPointOfInterestFilter.including(const [...])`).
- **`MKMapViewController`**: from `onMapCreated` (non-null inside/after); serial queue (no manual locking); auto-disposed on unmount; interface -> mock directly (`MockSpec<MKMapViewController>`). `camera`/`region`/`convertToPoint`/`convertToCoordinate` return `null` pre-layout. `setCamera`/`setRegion`/`setCenter(animated:)`; `selectAnnotation`/`deselectAnnotation` (`false` if id absent; select works on hidden annotations), `isAnnotationSelected`; `takeSnapshot(MKMapSnapshotOptions(...))` (draws annotations & overlays on iOS+macOS); `openLookAround(coordinate)` (`false` only when no scene); `addTileOverlay`/`removeTileOverlay` (`false` if unknown).
- **Errors**: `ArgumentError` (bad args/dup ids); the rest subclass `MapKitException`: `MapKitUnsupportedPlatformException` on any non-Apple platform incl. web, and for an iOS-only setting on macOS (`feature` names it); `MapKitDisposedException` (post-dispose controller call); `MapKitPlatformException` with `code`: `snapshot-failed` (bad/404 tile, 60s timeout, >1024 tiles, unprojectable tile, map disposed mid-snapshot), `look-around-failed`, `unsupported-platform` (`openLookAround` on macOS), `duplicate-id` (`addTileOverlay`), `invalid-icon` (bad bytes/SF Symbol), `unavailable-poi-category` (iOS 18/macOS 15 on older OS), `invalid-argument`. Declarative batch errors go to uncaught zone (batch stays unapplied; next set change resends all). Delegate errors -> `onDidFailToLocateUser` (e.g. no permission) / `onDidFailLoadingMap` (payload = description).
- **Callbacks**: `onSelect`/`onDeselect` per annotation (`onSelect` = tap or `selectAnnotation`; no `onTap` on annotations); `onMapFeatureSelected` requires `selectableMapFeatures`; `onDragStart`/`onDragEnd` require `isDraggable: true` (callback that could never fire throws `ArgumentError`). `onCameraMove` is continuous; `onUserTrackingModeChanged` reports MapKit mode changes (e.g. `none` after pan) — sync `userTrackingMode` via it. Sync throws in callbacks -> `FlutterError.onError`; async -> zone. `copyWith(x: null)` clears nullable fields.
- **Tap capture (explicit)**: overlays need `consumeTapEvents: true` for `onTap` (setting `onTap` without it throws); annotations need `calloutConsumesTapEvents: true` + `title`/`subtitle` for `onCalloutTap` (fires on bubble, not pin). Top-most capturing overlay wins; polyline hit area = `max(lineWidth / 2, 8)` pt.
- **Config**: `preferredConfiguration:` holds elevation/emphasis/POI/traffic only; `MKMapView` direct params hold `isZoomEnabled`, `showsCompass`, `showsUserTrackingButton`, `cameraZoomRange`, `cameraBoundary`, `selectableMapFeatures`, `layoutMargins`…. `layoutMargins`: `EdgeInsets?`, finite/non-negative edges; `null` restores UIKit defaults.
- **iOS-only** (throw on macOS): `selectableMapFeatures`, `onMapFeatureSelected`, `insetsLayoutMarginsFromSafeArea: false`, `layoutMargins` (even `.zero`), `userTrackingMode: followWithHeading`, annotation `calloutConsumesTapEvents`. Both platforms: `showsUserTrackingButton`, image `anchorPoint`.
- **Camera**: google_maps_flutter dialect via the `CameraConveniences` extension (`zoomTo`/`zoomBy`/`zoomIn`/`zoomOut`/`scrollBy`/`fitCoordinates`/`getZoomLevel`) over the canonical calls — throws `StateError` pre-layout, `ArgumentError` on `fitCoordinates([])` or padded span >180°/360°. `MKMapCamera.distance` = meters (`centerCoordinateDistance`); `MKMapCamera.withZoomLevel(...)`/`camera.zoomLevel` approximate Web-Mercator zoom.
- **Marker imagery**: `MKAnnotationIcon.marker(markerTintColor:, glyphText:, systemImage:, glyphTintColor:)`, `.image(pngBytes)`, `await MKAnnotationIcon.asset('assets/pin.png')`.
- **Naming**: `MKMapEmphasisStyle.standard` = Apple `.default`; `isHidden` replaces `visible`; `MKPolyline.geodesic(...)` = `MKGeodesicPolyline`; `Coordinate` = typedef `CLLocationCoordinate2D`; enum typedefs alias generated `Platform*` enums.
- **Permissions**: `showsUserLocation: true` requires `NSLocationWhenInUseUsageDescription` in `ios/Runner/Info.plist` (macOS: `macos/Runner/Info.plist` + Location sandbox entitlement) and app-initiated authorization — map never prompts.
