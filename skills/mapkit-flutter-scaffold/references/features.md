# mapkit_flutter features, camera & overlays

- **Controller calls**: `setCamera`/`setRegion`/`setCenter(animated:)`, `selectAnnotation`/`deselectAnnotation` (`false` if id absent; select works on hidden annotations), `isAnnotationSelected`, `takeSnapshot(MKMapSnapshotOptions(...))` (draws annotations & overlays on iOS+macOS; `snapshot-failed` covers bad/404 tiles, 60s timeout, >1024 tiles, unprojectable tile, map disposed mid-snapshot), `openLookAround(coordinate)` (`false` only when no scene; throws `look-around-failed`, `unsupported-platform` on macOS), `addTileOverlay` (throws `duplicate-id`) / `removeTileOverlay` (`false` if unknown).
- **Callbacks**: `onSelect`/`onDeselect` per annotation (`onSelect` = tap or `selectAnnotation`; no `onTap` on annotations); `onMapFeatureSelected` (iOS, requires `selectableMapFeatures`); `onDragStart`/`onDragEnd` require `isDraggable: true` (callback that could never fire throws `ArgumentError`). `onCameraMove` is continuous; `onUserTrackingModeChanged` reports MapKit mode changes (e.g. `none` after pan) — sync `userTrackingMode` via it. Sync throws in callbacks -> `FlutterError.onError`; async -> zone. `copyWith(x: null)` clears nullable fields.
- **Tap capture (explicit)**: overlays need `consumeTapEvents: true` for `onTap` (setting `onTap` without it throws); annotations need `calloutConsumesTapEvents: true` + `title`/`subtitle` for `onCalloutTap` (iOS only, fires on bubble). Top-most capturing overlay wins; polyline hit area = `max(lineWidth / 2, 8)` pt.
- **Config & iOS-only props**: `preferredConfiguration:` holds elevation/emphasis/POI/traffic only; `MKMapView` direct params hold `isZoomEnabled`, `showsCompass`, `showsUserTrackingButton`, `cameraZoomRange`, `cameraBoundary`, `selectableMapFeatures`, `layoutMargins`…. iOS-only (throw `MapKitUnsupportedPlatformException` on macOS): `selectableMapFeatures`, `onMapFeatureSelected`, `insetsLayoutMarginsFromSafeArea: false`, `layoutMargins` (`EdgeInsets?`, finite/non-negative edges; `null` restores UIKit defaults), `userTrackingMode: followWithHeading`. Works on both: `showsUserTrackingButton`, image `anchorPoint`.
- **Camera & geodesics**: `CameraConveniences` extension (`zoomTo`/`zoomBy`/`zoomIn`/`zoomOut`/`scrollBy`/`fitCoordinates`/`getZoomLevel`) wraps canonical calls — throws `StateError` pre-layout, `ArgumentError` on empty `fitCoordinates([])` or padded span >180°/360°. `MKMapCamera.distance` = meters (`centerCoordinateDistance`); `MKMapCamera.withZoomLevel(...)`/`camera.zoomLevel` approximate Web-Mercator zoom. Geodesics: `MKPolyline.geodesic(...)`.
- **Marker imagery**: `MKAnnotationIcon.marker(markerTintColor:, glyphText:, systemImage:, glyphTintColor:)`, `.image(pngBytes)`, `await MKAnnotationIcon.asset('assets/pin.png')`.
